# Issue rubric

A starting point. Rewrite it — every triage verdict is only as good as this
document, and a generic rubric produces generic verdicts.

## §1 — priority: low

Cosmetic or documentation-only. No behaviour changes. Trivially revertible.

## §2 — priority: high

A reproducible crash, data loss, or incorrect output from library code on
documented input. "Reproducible" means from the report alone.

## §3 — priority: medium

Wrong or surprising behaviour that has a workaround, or a crash that needs
unusual input to trigger.

## §4 — priority: low

Requests for new capability that nothing currently depends on.

## §5 — not a defect

Feature requests, questions, and design discussion. These get a tier of 2:
someone must decide the work is wanted before it is done.
